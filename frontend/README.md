# Hotel Service API Tester (Frontend)

Frontend dùng để test nhanh API backend của dự án hotel_service.

## Công nghệ

- ReactJS
- JavaScript
- Vite
- Tailwind CSS

## Chạy local

```bash
npm install
npm run dev
```

Mặc định frontend gọi backend tại `http://localhost:9000`.

Nếu cần đổi, tạo file `.env`:

```bash
VITE_API_BASE_URL=http://localhost:9000
```

## Build

```bash
npm run build
```
